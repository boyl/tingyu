# tingyu：播放控制、存储与账号设计提案

## 一、现状核对

- 播放器已有底层 speed 状态，但没有完整倍速、睡眠停止计划的交互与状态契约。
- 设置 `/settings/downloads` 直接复用了 DownloadsPanel，与主下载页职责重复；容量数字仅由已完成任务累加，不能代表真实应用文件总占用。
- 设置头像进入账号面板，旁边的收藏夹导入也进入同一面板，入口重复。
- 当前玻璃表面使用固定透明度；歌词已有翻译/罗马音偏好，没有统一的播放页展示开关。
- 启动背景仍是原生模板白色面，透明白色启动器图标不适合直接搬到白色启动屏。
- 既有播放器、歌词和拖拽相关工作需要保留回归边界；本轮先确认新的逻辑与视觉，不据此宣称旧实现已验收。

## 二、体验目标与入口

用户核心任务是在播放时方便地控制“以什么速度听、什么时候停、是否看歌词”，并在设置中管理偏好、账号和真实空间占用。

- 播放页：唱片、曲名/UP 主、歌词（可关闭）、进度与原有控制；增加一个“播放设置”入口，状态摘要只在非默认时出现。
- 播放设置底部面板：倍速、歌词展示、停止计划。停止计划的“持续播放 / 本首播完 / 定时关闭”互斥，避免两个停止规则交叉。
- 定时关闭子面板：15/30/45/60 分钟及自定义；结束方式为“到时暂停 / 本首播完”。底部确认后才生效，返回或取消不改现有计划。
- 设置：单一账号卡片、原有四主题、播放偏好/播放页歌词、玻璃透明度、存储空间、关于。设置页本身保持清晰实色背景。
- 存储空间：环形分类图、总量、逐项大小/比例；任务和歌曲的操作仍在下载页，必要时以明确的“查看已下载”跳转。
- 账号：连接/登录管理、唯一的收藏夹导入入口、退出；头像只展示，不再形成第二个导入入口。

## 三、播放逻辑

### 1. 本首播完暂停

一次性计划，绑定确认时的当前曲目；自然播放完成后暂停，不自动下一首，不改变原有列表循环/单曲循环/随机模式，也不清空队列。提示状态“本首播完暂停”。手动切换曲目则取消这个绑定，给出一次明确反馈；暂停/继续、进度拖动和修改倍速保留计划。无当前曲目时禁用。

### 2. 定时关闭

这里的“关闭”默认指结束本次播放：暂停、关闭倒计时、保留进度及队列，不强制杀应用。UI 在选择处明确说明，避免丢失任务或误以为强制退出。

- 计时使用现实经过时间，不随倍速缩放；暂停、缓冲、后台和锁屏时继续计时。
- “到时暂停”：到期停止当前播放；已经暂停则直接结束计划，不能因为定时器恢复播放。
- “本首播完”：倒计时到期后等待当时正在播放的曲目自然结束；若已经暂停、没有曲目或处于失败状态，则立即结束计划。到期前仍可正常连续切歌。
- 新建计划替换旧计划；手动取消立刻清除倒计时。绑定本首计划和倒计时计划不能同时生效。
- 默认不跨进程重启恢复停止计划；启动保持暂停，不能恢复一个过期停止动作。未来若需要恢复必须单独设计。

### 3. 倍速与歌词

- 倍速范围 0.5×–2.0×，常用 0.75/1.0/1.25/1.5/2.0，支持 0.05 步进的细调。设置在切歌/暂停/离线播放中保持，重启保留偏好但不自动播放；失败回到原值并提示。
- 倍速改变不影响真实时间的睡眠倒计时；歌词按音频播放位置同步。
- “播放页歌词”只控制唱片页里的歌词区域，关闭后空间归给唱片与元信息；独立歌词页仍能主动打开，缓存、匹配、翻译和罗马音设置不删除。
- 设置页与播放设置面板使用同一个偏好，不能出现互相矛盾的两个开关。
- 已下载圆圈勾选是状态展示，不是按钮、不设点击回调、不进入下载页；保留“已下载”的无障碍描述。歌曲行仍正常播放，文件管理在下载页/更多菜单。下载中/失败/尚未下载的交互另按原契约保留。

## 四、玻璃、启动与账号

### 自动玻璃

设置命名“玻璃透明度”，提供“自动 / 手动”。自动时根据底下内容复杂度与文字可读性调节背景不透明度；使用平滑变化和迟滞，不能每帧跳动。手动时显示“更通透—更清晰”滑杆，滑杆只改变背景表面，不改变图标、标题或点击区。

作用范围仅为底部迷你播放栏与导航栏，两者共用偏好；设置页不改回整页磨玻璃。四主题分别校验，系统要求降低透明/高对比时优先可读性。效果稿的 24%–58% 是说明用示例，不作为未经设备验证的算法阈值。

### 启动屏

系统启动帧与应用启动帧保持同一背景、图形中心和尺寸，避免跳位、双闪、圆形遮罩裁切。启动页沿用同一折带轮廓，白底使用主题强调色；桌面白色图标母版不因此更改。

建议冷启动从首次可见启动帧计总展示约 0.8–1.0 秒，准备完后淡入；热启动不额外等待。数据加载慢时切为明确“正在恢复音乐库”状态，失败提供重试，不能为动画阻塞真正可用界面。减少动态时直接切换。

### 账号去重

设置只有一张“账号与收藏”卡片：登录后显示用户名/连接状态，整卡进入账号页；不再单列同义的“导入 B 站收藏夹”。账号页里头像为资料展示，下面唯一的“导入收藏夹”进入真实选择流程。未登录时给一个“连接 B 站”主入口，导入说明登录后可用；账号失效提供重新连接，不重复导入、不清空本地歌单。退出需说明保留本地音乐与下载。

## 五、存储空间

改名避免与下载任务管理混淆。环形图分母是“tingyu 可统计的自有文件”，不是整机空间；设备剩余容量单列，不混进分类圆环。分类：已下载音频、封面缓存、歌词、临时文件、其他应用资料（含数据库及未单列自有文件）。

按实际磁盘文件统计、去重，不按任务声明 received 估算；统计中、权限/读取失败、空空间和外部文件变化都有状态。环图与列表必须来自同一份统计，比例总和一致。清理临时文件先确认且跳过仍在使用的下载/导出临时文件；已下载歌曲不作为“缓存一键清理”目标。清理成功重新统计，失败显示原因。

稿件使用示例数据：3.20 GB = 音频 2.56 GB (80%) + 封面 320 MB (10%) + 歌词 32 MB (1%) + 临时 224 MB (7%) + 其他 64 MB (2%)。采用十进制示例口径；实现需统一单位并说明系统统计差异。

## 六、状态与恢复矩阵

| 场景 | 反馈与允许操作 | 保留/清理 |
|---|---|---|
| 未播放/空队列 | 倍速偏好可设，本首计划禁用；定时器不能恢复播放 | 保留偏好 |
| 修改播放设置 | 选择即反馈；定时器编辑确认后生效，取消保留旧计划 | 非默认状态摘要 |
| 自然完成/停止计划到期 | 根据唯一停止规则暂停或等待本首结束 | 计划一次性清除，队列/进度保留 |
| 手动切歌 | 普通计时继续；绑定本首计划取消并反馈 | 倍速、歌词显示保持 |
| 返回/重进/重启 | 返回保留页面偏好；重启暂停、停止计划不恢复 | 不丢下载和歌单 |
| 空间统计中/失败 | 占位进度或原因与重试，不显示假 0 B | 上次值标注，禁止无依据清理 |
| 清理临时文件 | 确认、处理中防重复、结果与重新统计 | 不删活动文件、音频、歌单 |
| 账号未登录/失效 | 连接/重连；收藏导入不可执行 | 本地歌单和下载不受影响 |
| 启动初始化慢/失败 | 恢复状态、失败重试 | 不停在纯装饰启动屏 |
