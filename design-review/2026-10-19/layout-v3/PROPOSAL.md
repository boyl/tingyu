# 听屿第三版设计（待确认）

本稿替代 layout-v2 中冲突的设计项；只新增设计资产和原型，不改应用源码、正式验收基线或发布包。Mac 暂停、仅 arm64-v8a 发布的约定保持。

## 核心体验与布局

- 核心任务：听歌时不离开歌曲详情，直接通过倍速、时钟图标调整对应行为；播放模式沿用单击轮换，操作后有短时名称提示。
- 倍速和定时采用同一紧凑浮层：同一标题字重、内边距、浅色播放器材质和关闭入口。移除上一版超大数字、卡片格子与大块确认按钮。
- 本稿展示默认哔哩粉。四主题共用结构，正式应用的材质、对比度和字体缩放仍需独立验证。

## 本轮明确修订

### 原图标保持

从 lib/ui/icons.dart 核对并还原：download 的竖箭头及圆角托盘，done 的半径9圆圈与7,12→10,15→17,8勾选；线宽1.7，圆端。原型下载导航及已下载完成态都使用这些路径，不重新设计原有图标。此次只新增倍速、时钟和必要的播完暂停图标。

已下载完成态仅取消独立点击/跳转，不取消圆圈。整行播放及更多操作仍可用，未下载仍触发下载。排队、下载中、暂停和失败保持原有状态处理。

### 播放模式

列表循环→单曲循环→随机播放→播完暂停→列表循环，点击现有模式按钮直接轮换，不弹窗、不增加长按选项面板。图标随模式更新，短时提示当前名称并更新无障碍标签。

播完暂停为持续选中的模式：本首自然结束暂停，不自动切下一首；手动播放、切歌保留该模式。倍速、定时不改模式。暂停、拖动和改模式不触发自动播放。

### 倍速与时钟直达

歌曲详情的倍速图标＋当前倍率直接打开倍速浮层；时钟图标直接打开定时关闭浮层，启用时旁边显示倒计时。不会先进入设置总页。

倍速：0.5/0.75/1/1.25/1.5/2 常用刻度，0.05精调，范围0.5–2；即改即用，无额外确认。关闭浮层保留已应用值，切歌和重启保留偏好；恢复正常为1×。

定时：时钟图标，15/30/45/60快捷项，时分选择，自定义总长1–180分钟。原型以可编辑数字模拟时分滚轮布局，不声称已完成原生滚动/吸附。

倒计时按真实时间，与倍速无关，后台/暂停/缓冲继续计时。可选到时等本首结束；结束只暂停，不退出进程，保留进度。已暂停/无曲/失败到时不恢复播放，直接结束计时。等待本首结束期间手动切歌则立即暂停并结束等待。新计时替换旧计时，取消只取消计时；重启不恢复旧计时。

### 三组透明度

同页从上到下：
1. 导航栏＋播放栏总控，置顶；
2. 导航栏独立控制；
3. 播放栏独立控制。

每组都有自动开关；手动为20%–85%背景不透明度滑杆。预览使用同一真实布局，文字/图标保持不透明。

- 总控操作：同时把两栏设置成所选自动/手动状态与数值，覆盖原来的独立值。
- 分控操作：只改对应栏。存在独立设置时总控显示“分别设置”，不再假装两栏仍共用数值。总控滑杆保留上次统一值，拖动后再次同步两栏。
- 自动取样阈值本稿不验证。示意预览自动26%，手动55%，独立导航38%/播放68%。四主题需采用可读材质回退、平滑过渡与减少动态支持。
- 保存模式和手动值；返回不回滚。预览与实际底部两个组件使用同一组状态。

### 启动屏

删除“正在恢复音乐库”，不把特定初始化任务作为品牌文案；同时移除常驻进度装饰。只显示品牌图标和名称，不强加口号。

保留图标柔角与比例；浅底主题色轮廓用于启动显示，不改变白色透明启动器母版。冷启动到应用首帧连续，热启动不刻意等待。原生启动衔接、总展示时长和异常恢复在实现阶段验证，不以原型静态画面代替。

## 状态与交互矩阵

| 入口/状态 | 行为与反馈 | 取消、失败、恢复 |
|---|---|---|
| 模式按钮 | 单击轮换，图标与短时名称提示一致 | 无弹窗；没有队列时仍可改偏好，不自动播放 |
| 倍速图标 | 直接展开；刻度/精调与当前倍率联动 | 关闭保留已应用值；引擎失败回退真实值并提示 |
| 时钟图标 | 直接展开；开始计时后详情显示剩余时间 | 超出1–180分钟保留输入并提示；取消清除计时 |
| 计时等待本首 | 截止时正在播放则等自然结束 | 不恢复已暂停内容，失败/手动切歌终止等待 |
| 总透明度 | 同步两栏，显示统一数值或自动 | 返回保留状态；取样失败采用可读回退 |
| 分透明度 | 只改对应栏，总控显示分别设置 | 不改变另一栏；重进恢复各自偏好 |
| 下载完成 | 原圆圈勾选，只展示状态 | 不跳下载页；歌曲行和菜单仍可操作 |
| 启动 | 纯品牌画面到内容首帧 | 不显示虚构处理任务；真实失败需恢复入口 |

## 验收提案与证据边界

- 新截图必须能看到原圆角下载箭头和圆圈完成勾选；只新增必要图标，原有图标不顺带重画。
- 点击播放模式没有任何选项弹层，循环四模式与名称提示一致。
- 点击歌曲详情倍速/时钟直接进入对应浮层，关闭回到歌曲详情；不新增中转页。
- 倍速首项0.5×，即时更新倍率；定时统一使用时钟，不用月亮或秒表代替。
- 透明度必须同页呈现总控、导航、播放三组，总控置顶；验证统一、独立、自动及“分别设置”反馈。
- 启动品牌画面没有恢复音乐库文字、虚构进度或加载装饰。
- 原型检查包括图片加载、无脚本报错、直接展开、倍速回显、定时回显、模式提示、总分控联动和资源链接；不能等同于Flutter或设备测试。
- 未运行原生音频、后台定时、系统启动、文件操作、字体放大、四主题与横屏验收。确认后再实现，并同步正式功能、UI、验收及发布文档。
