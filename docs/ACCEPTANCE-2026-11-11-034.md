# 0.1.34 长按与右键菜单发布验收

## 范围与验收标准

- 用户要求“发布安装”；Android arm64-v8a 与 Mac 更新为 0.1.34+35，Windows 沿用 0.1.33。
- Android 精选卡片移除封面三点，长按封面/标题打开菜单；Mac 精选卡片改用右键。列表保留行尾更多，普通、推荐、下载、历史和队列沿用各自上下文菜单；只有推荐内容显示“不感兴趣”。
- 长按松手与右键不得播放，横纵滚动取消长按，多选模式不改变；手机队列通过右侧拖动柄排序。Mac 保留 Shift+F10 / 菜单键和辅助功能入口。
- 最终版本运行工程及隔离 Android 导航、交互、导出、滚动、真实播放门禁；同一 APK 完成系统栏、签名、唯一 ABI、版本和摘要校验。
- Mac universal Release、ad-hoc 签名、DMG 完整性与挂载内应用校验；正常退出旧版后覆盖安装到 `/Applications/tingyu.app`，不备份、不清除用户数据，核对安装版本、签名与文件一致性。
- README 在上传前更新功能、版本、三端下载表和 Android/Mac 搜索截图；发布后回读非草稿 Release、标签提交、两项新资产及摘要。
