## 跨功能必须保持的约束

- 曲目标识以 `bvid:cid` 为准。解析占位 CID 后更新集合引用，重复加入不生成重复歌曲，不改变曲库稳定顺序。
- 播放、队列、喜欢、歌单、排序和下载状态经数据库恢复后保持一致；恢复后不擅自自动播放。UI 和系统播放按钮不能各自维护不同状态。
- 异步按钮完成前抑制重复触发；过期搜索/播放/歌词请求不能覆盖更新的状态。控件销毁后不再写入 UI 控制器。
- 取消编辑、选择、导出不提交未确认数据；删除下载不删除歌曲关系，移除歌单成员不停止或删除仍有效的当前音频。
- 发生网络、解析、存储、音频或凭据失败时保留可恢复数据，显示原因和恢复入口；缺失或不完整文件不能冒充离线可播。
- UI 复用 TingyuTokens、Pressable、统一图标与共享列表组件；相同动作在不同页面使用同一语义与状态。

## 已实现不等于全场景已验收

- 匿名公共 BV 的原生解码、下载和离线回放与账号登录/收藏权限是不同证据。夹具通过不能代表真实登录或接口风控通过。
- 物理 Android 的听感、截图时音频输出、蓝牙、耳机、来电、锁屏、厂商后台省电需要真机复验；模拟器进度前进不代表人耳可听。
- 桌面服务代码或包脚本测试不代表 macOS/Windows 已完成真实窗口、媒体键、托盘与分发验收。Mac 新设计仍不在当前工作范围。
- 系统启动器可给透明图标添加底板/遮罩；源图和 APK 内透明性、具体桌面外观分别验收。

## 当前不提供或不保证的能力

- 不实现 HTTP Range 断点续传；中断任务重试重新下载，不对不同临时 URL 拼接。
- 不保证 Android 进程被系统结束后仍继续下载；不保证规避厂商省电限制。
- 没有跨设备同步、车载专用界面、复杂音效、音量均衡和自动更新。
- 没有正式商店签名、公证、商店上架或自动发布承诺；CI 为手动触发。
- 不把早期提案中的模拟数据、未确认 UI 或已取消的磨玻璃设置算作已有功能。

## 0.1.19 修订（待最终原生与包验收）

- 透明度定义为背景透明程度：0%不透明、100%背景透明；整体同步向两栏写值，独立微调不反向移动总控。自动恢复74%透明度基准（alpha .26）；常驻共享底栏预览＋可选原位按住预览。
- 存储统计加入系统安装占用，与自有文件分类分开；查询失败标记未含安装。临时清理保护不变。
- 歌词正文操作归并三个点；显示/排版即时保存，编辑及偏移明确保存，候选先预览确认替换。收藏夹增加查找、多选、批量导入，部分失败保留剩余选择。
- 登录会话优先唤起官方B站App的会话地址；二维码备用。唤起不作授权成功判据，仍以后续轮询结果为准。
- 迷你播放器导航独立处理，不等待路由Future而锁住缓存入口；移除下载不移除歌曲/歌单/喜欢。产品名称统一tingyu，数据及标识不迁移。
