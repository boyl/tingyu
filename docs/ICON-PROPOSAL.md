# 图标分配方案 · 已确认实施

用户已确认三组布局及歌单内部操作；按本稿实施到界面。使用项目现有 Material 图标字体绘制，延续 A/B/C 主题；避免确认图和实际图标不一致。

## 分配

| 场景 | 图标与位置 | 行为 |
|---|---|---|
| 应用菜单 | 音乐库左上三横 `menu` | 侧栏收纳账号、收藏夹导入、设置、关于 |
| 当前内容操作 | 歌曲/歌单三个点 `more_horiz` | 当前内容的加入歌单、改名、删除等操作 |
| 页面返回 | 左箭头 `arrow_back` | 返回来源页，继续播放 |
| 新建歌单 | 音乐库右上 `playlist_add` | 替代常驻“新建歌单”文字按钮 |
| 音乐库导航 | `library_music_outlined` | 和播放队列图标区分 |
| 搜索 / 下载 / 喜欢 | 放大镜 / 下载箭头 / 心形 | 底部保留短导航名，搜索集中到底部入口 |
| 播放模式 | `repeat` / `repeat_one` / `shuffle` | 直接点击轮换；长按展示当前模式 |
| 播放队列 | `queue_music` | 查看和调整播放顺序 |
| 播放控制 | 标准上一首 / 播放暂停 / 下一首 | 避免用其他近似三角符号混用 |
| 歌词 | `lyrics_outlined` | 歌词匹配及手动设置入口 |
| 下载状态 | 箭头 / 时钟 / 进度环 / 勾选 / 暂停 / 叹号 | 对应未下载、排队、进行、完成、暂停、失败；失败点击重试 |
| 次要操作 | 铅笔 / 垃圾桶 / 齿轮 / 信息圆圈 | 收进当前内容更多或应用菜单，删除仍须确认 |

音乐库页不重复放搜索和账号按钮：搜索在底部，账号在三横菜单。页面只保留必要文字；控件最小 48 px，长按、键盘焦点和无障碍标签保留完整含义。
