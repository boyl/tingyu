# 0.1.9 滚动与向当前歌单添加歌曲

## 体验约定

- 核心任务：在当前歌单添加歌曲。入口是歌单“添加歌曲”，不改变新建歌单流程。独立选歌页默认音乐库，支持本地搜索、多选，底部“添加 N 首”一次提交。
- 已添加歌曲标记且不可重复选择。未选时提交禁用；取消或系统返回放弃未提交选择。成功返回原歌单，已有页面和滚动位置保留。
- “在线搜索”是选歌任务的子页面，可试听、直接添加到当前歌单；成功后图标变为已添加。返回选歌页保留未提交的本地选择，已在线加入的歌曲不重复计数。
- 选歌及其在线搜索隐藏全局分类导航。普通分类切换恢复各分类最后页面与滚动现场；当前分类再次点击返回该分类根页。歌单左上返回音乐库首页。跨分类无过渡闪页。

## 状态与恢复

| 状态 | 显示与操作 | 退出/恢复 |
|---|---|---|
| 初始 | 本地歌曲、已添加标记；提交禁用 | 返回不改歌单 |
| 空音乐库/无匹配 | 明确空态；在线搜索入口可见 | 清除搜索或在线查找 |
| 已选 | 选择图标和添加数量；筛选不清除选择 | 在线搜索往返保留选择 |
| 正在提交 | 禁用重复提交与返回，正在添加 | 完成自动返回 |
| 添加成功 | 原歌单立即显示新增歌曲 | 重进不重复添加 |
| 保存失败 | 原因可见，选择保留 | 重试；已失败提交恢复原歌单 |
| 目标被删除 | 提示并提供音乐库出口 | 无悬空任务 |
| 在线搜索失败 | 保留搜索与当前目标，重试入口 | 返回本地选歌 |

## 性能变更及测量边界

- 原实现每次播放进度事件通知整个 ChangeNotifier，触发曲库/歌曲行重建；音乐库/歌单/下载由 SingleChildScrollView + Column 一次布局全部行。
- 进度改为独立 ValueNotifier，仅进度条和歌词监听；播放状态、歌曲切换和下载等业务变更仍更新相应视图。
- 三类长列表用 SliverChildBuilderDelegate 按需构建，并由行重绘边界隔离；保持原内容面和圆角。封面文件解析在异步服务处理并复用命中，绘制不执行同步 exists 检查；保留原有高清解码尺寸和封面原件，不以降低封面清晰度换取性能。
- 懒加载行绑定构建时不可变曲目快照，避免 CID 解析替换标识后、通知发布前滚动读取旧 ID 产生异常；补齐该异步窗口的滚动回归。
- 新增工程回归：500 首曲目只挂载可视/预取行；100 次进度事件不通知全局、不替换曲库行；歌曲、进度、歌词、选择和导航原有行为继续回归。
- 原生 Profile 场景：500 首、1024px 本地封面、20Hz 播放进度模拟、三页各 8 次定速上下拖动，引擎 FrameTiming 输出 build/raster P50/P95/max/超过16.67ms帧数。歌曲顺序、封面数据和手势一致；热身后采样。
- 模拟器虚拟 GPU 与宿主负载会影响绘制结果；模拟播放进度不等于真实音频输出。不得据此宣称实机 60/120fps 或滚动模糊已实机解决。真机复验仍需用户执行。
