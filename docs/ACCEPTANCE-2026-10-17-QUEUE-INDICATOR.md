# 0.1.10 队列音柱、长列表回顶与下载分页

## 已确认行为

- 队列当前歌曲统一三根圆角音柱，尺寸、颜色和布局不随播放状态切换。
- 播放时仅重绘音柱；暂停、停止、完成和减少动态效果时使用固定的长短轮廓，不随机停在另一种形状，不保留动画计时器。
- 后端停止后即使仍保留 playing 意图，队列也应静态显示。
- 音乐库、喜欢、歌单、下载、搜索和队列滚动超过一屏后，右下角出现 48 px 回顶箭头；到顶自动隐藏。主列表按钮位于迷你播放器上方，队列按钮位于队列列表内；末尾预留避让空间，不能遮住最后一首的操作。
- 点击平滑回顶；系统减少动态效果时直接回顶。回顶不改变歌曲、队列顺序、播放状态或分类现场。
- 只有小型按钮在跨过阈值时重建，列表继续按需构建。

## 下载页

- 默认进入“已下载”；右侧“下载任务”展示下载中、等待、暂停和失败及任务数。开放文字 Tab 与内容共用暖白底，以字重和短线标记选中，三主题使用同一组件。两页各自保留搜索、滚动和回顶；空页仍保留切换入口并说明状态。
- 已下载按音频完成时间倒序；完成时间与任务状态一起持久化，重试重新下载后采用新的完成时间，歌词和封面补全不改变排序。
- 排序仅生成展示快照，不修改下载队列或播放来源。时间相同时采用确定的入队顺序，重启不会漂移。
- 本机已有完整音频可从文件修改时间恢复时间信息；缺失或损坏文件仍进入失败任务，不会误列为已下载。不增加版本迁移层。

## 自动验收标准

1. 动态音柱的连续两帧像素不同；暂停与停止各自两帧一致，且两种静态状态轮廓相同。
2. 暂停、恢复、停止前后位置与尺寸一致；停止意图保留场景也显示静态。
3. 短列表与顶部隐藏回顶按钮；长列表下滑后显示，点击回顶并隐藏，触控区域至少 48 px。
4. 覆盖普通和减少动态效果；原生音乐库与 51 首队列执行回顶操作，检查按钮不覆盖最后一首的移除操作，并保留原导航及播放回归。
5. 下载任务与已下载分页，完成时间倒序、持久化往返、重试完成时间更新、底层任务顺序不变；原生失败任务完成后留在任务页，点击已下载才显示文件；完成不自动跳页。
6. 执行统一源码指纹门禁、同源分 ABI Release 验包、全屏及刘海方向检查，再交付人工验收。

## 搜索外跳入口

搜索空态入口改为“前往哔哩哔哩”，使用独立边界与外部打开图标，附小字说明优先 App、未安装使用浏览器。Android 仅查询两种官方客户端包并启动已安装客户端；缺失或受限时显式调用外部浏览器，不进入内置 WebView。重复点击只触发一次；浏览器不可用时提供错误反馈。

App 已安装、缺失、启动失败、浏览器失败及防重复点击在主机测试覆盖；原生未安装桥接在独立 AVD 验证，实际安装 B 站后的跳转仍需实机复验。隔离模拟器上的 Chrome 首次引导不把 data URI 写入活动转储，检查会先关闭该引导，并同时保留 ActivityTaskManager 的 VIEW 启动记录。Tab 与入口已按最终确认图实现；两页回顶独立，已完成/进行中图标进入对应分页。

机制参考：[url_launcher 官方文档](https://pub.dev/packages/url_launcher)；客户端优先调用 Android 已安装包启动入口，不依赖默认 HTTPS 关联。

搜索空态与外跳按钮的文字/图标通过控件几何检查居中；不能仅凭手工预览定位判定居中。
