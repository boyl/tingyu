# 0.1.5 独立设置页验收

## 范围

按确认稿移除侧滑抽屉与重复入口，改为独立设置页。音乐库齿轮和桌面设置进入同一页面；账号卡片、三主题直接选择、音质、下载管理及关于均接入现有业务控制器。下载管理使用独立子路由，避免重新创建主导航。

## 体验与状态

- 核心任务：打开设置 → 切换主题/音质或进入账号/存储 → 返回原页面。完成证据是偏好持久化、导入成功、播放持续、来源输入和位置保留。
- 未登录：账号卡片提供登录，导入禁用并显示“登录后”；已有凭据时可进入账号面板刷新状态，失效可重新扫码。
- 处理中/失败/恢复：账号继续沿用生成二维码、过期刷新、扫码确认、导入反馈和重试；设置偏好保存仍通过现有错误报告边界处理。
- 返回：固定左上返回与系统返回；直接进入设置时回音乐库，存储子页面返回设置。设置中隐藏主导航与迷你播放器，不停止音频。
- 主题：共用语义颜色、文字、48 px 最小目标和减少动态效果；选中边框加勾选。小屏可滚动，桌面限制内容宽度。

## 验证

本轮执行 `tool/run_acceptance.py --device emulator-5558`：静态、离线、打包工具、Android 导航及完整交互。未改播放/下载服务，不重复匿名联网探测；0.1.4 的真实公共 BV 证据作为历史记录，不能标为本次执行。

新增覆盖独立设置的系统/按钮返回、深链回退、来源输入和播放保留、三主题、音质与存储返回；原生截图保存设置暖白/深色/冷白。保留 25 收藏夹导入、歌单、队列与下载故障恢复回归。

最终状态以 `artifacts/acceptance/report.json`、Release 生命周期与 `tool/verification.json` 为准。模拟器失声按用户要求暂缓，Magic5/MagicOS 7.1 实机待用户验收，不在本轮宣称修复。原人工 AVD 只允许同签名 Release `install -r`，本轮不重启、不卸载、不清理资料。
