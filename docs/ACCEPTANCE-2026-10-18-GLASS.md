# 0.1.13 通透底栏与状态一致性

用户确认第 5 版视觉稿后实施。参考稿在 `design-review/2026-10-18/revision-v5.png`；示例歌曲仅用于设计，正式应用继续使用用户真实曲库。

## 实施内容

- 哔哩粉强调色 #FB7299，中性白底与深色正文；小号状态文字使用独立的可读墨色，主按钮采用深色图标/文字。
- 共享 GlassSurface 使用 5px 模糊、低不透明度覆层、细高光边缘与轻阴影；手机 Scaffold extendBody，让列表实际滚过播放栏和导航背后。末尾与回顶按钮按底栏实测高度避让；安全区保留。
- 去除曲库/喜欢/歌单连续歌曲列表外的大块内容面；当前行仍有淡色标记。首页标题与 UP 主移到大封面上方，封面仍提供内容色彩；歌单/主题的横向侧露布局保留。
- 已喜欢为实心红心，未喜欢为空心；圆圈对勾统一用于多选、下载完成和主题/音质选中。下一首与入队使用不同图形。
- 歌曲菜单使用“加入播放队列”；队列菜单显示歌曲与当前位置，动作改为“移至下一首 / 上移一位 / 下移一位 / 从队列移除”。暂停下载使用继续符号，失败才用重试。
- 手机歌词编辑改为底部表单、键盘避让，偏移以 0.1 秒步进，保存与取消语义保持。
- Android 启动与窗口恢复使用显示系统栏，取代主动隐藏；边到边背景不变。状态栏和导航栏图标随明暗主题变化。

新增图标像素回归覆盖红心内部填充、跳转/入队图标差异以及选择/完成共用圆圈对勾；现有交互测试改用新文案和歌词步进，并继续检查取消不保存。

Android 交互回归通过主机 driver 发送 KEYCODE_SYSRQ 请求系统截图，随后检查仍播放、进度前进、播放器增益不变。该证据只能证明此隔离模拟器路径，不能代替手机截图声音、耳机、蓝牙和厂商系统音频焦点实测。播放服务未添加强制恢复或猜测性音频焦点补丁。

## 玻璃性能边界

根据 Flutter 官方 BackdropGroup / BackdropFilter.grouped 机制，两个不重叠底栏共用背景输入，避免重复模糊。相同软件渲染模拟器中，分组前库页 raster p95 为 102.494ms，分组后一次定向样本为 78.091ms；下载/歌单变化很小。该优化未消除模拟器上的模糊绘制成本，不能宣称达到真机 60fps。2px 半径试验未形成有效的 100 帧样本，不作为性能改善证据；最终保留已确认的 5px 外观，并延长测试拖动样本以保留原有最小 100 帧要求，原始耗时照实记录。低端安卓上的玻璃流畅度列入人工验收，未标 PASS。

依据：https://api.flutter.dev/flutter/widgets/BackdropGroup-class.html
