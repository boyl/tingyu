# 0.1.32 输入法空格确认修复发布

## 范围与兼容性

- 用户在安装本机修复版后表示“可以发布了”；Android 与 Mac 更新至 0.1.32+33，Android versionCode 2033。Windows 保留已公开的 0.1.31 安装程序下载链接。
- 发布前整合远端 `cc6af868cb30fcd46c6c101c9f928d73604ecea4`：保留 Windows 补充发布记录、推荐封面状态修复和共用界面修复，不覆盖远端历史或旧发布资产。
- 输入框获得焦点时，空格在快捷键匹配阶段即排除，交回原生输入法；非编辑状态仍可空格播放/暂停。用户数据、接口和搜索布局保持不变。
- Android 保留原开发签名，Mac 使用未公证 ad-hoc 签名。Windows 旧包不包含本次输入法修复。

## 验收标准

- Mac/Windows 组件测试：组词、普通文本和本地搜索中的空格均未被播放快捷键消费；模拟输入法提交中文成功，离开编辑状态后快捷键仍切换播放。
- 最终版本的工程、隔离 Android 导航/交互/导出/滚动/真实播放门禁通过，并核验同源最终 APK 系统栏。
- 仅构建 Android arm64-v8a；核对版本、ZIP、唯一 ABI、原证书和 SHA-256。Mac universal Release、应用及 DMG 挂载内签名、DMG 完整性和版本均通过。
- 发布前后核验正文、两项新资产、下载链接、版本标签和服务器摘要。Windows 链接与现有发布资产一致。
