## 修复证据
1. 原页面使用独立路由重建；改为持久分支、无整页切换动画，搜索控制器在 initState 初始化，修复销毁期读取 ref 异常。
2. 内容区横向布局拉伸占满高度，修复空页面垂直居中导致的顶部大留白。
3. Android 用原生 WindowInsetsController 控制系统栏，在窗口恢复和键盘收起后恢复全屏，保留边缘手势，已自动验证呼出后再次隐藏。
4. 收藏夹从狭窄滚动对话框改为手机底部大面板：固定头部、独立滚动列表、两行标题、单选反馈、固定导入与成功入口。桌面保留有明确最大宽高的对话框。
5. 主机 HTTP 代理曾阻断本机调试连接；Flutter 包装脚本仅为 localhost 增加代理绕过，不更改系统代理。最终两次完整驱动均成功返回。

工程专项已完成；全量门禁中的 NOT RUN 仍是正式交付阻塞项。后续改动须按同一标准重新执行受影响门禁，并附新版日志和产物指纹后再提交人工验收。
