# 0.1.36 封面缓存修复发布验收

## 范围与验收标准

- 用户授权修复并发布封面缓存问题；Mac 与 Android 目标版本为 0.1.36+37，Windows 保留 v0.1.34 原 EXE。
- 在共享 `covers.dart` 中串行执行缓存维护，分开处理图片加载成功与容量维护失败，避免并发清理将已落盘图片误报为空。不增加平台分支或旧版兼容层。
- 在接近 64 MiB 上限的隔离缓存中复现四路并发，先保留失败证据，再验证首次返回、重复读取、就绪状态与容量维护；真正加载失败仍保持既有语义。
- 最终工程及隔离 Android 原生/真实服务门禁使用同源报告；Android 包核对唯一 arm64-v8a、versionCode 2037、原开发签名、系统栏及 SHA-256。
- Mac Release 核对 universal 架构、最低系统、严格 ad-hoc 签名、DMG 完整性及挂载副本一致性。发布前同步 README 与清单，发布后回读非草稿状态、标签提交、两项资产及重新下载摘要。
- 本次不改布局，沿用已有截图及来源说明；不将历史截图称为本轮新截图。

## 已观察问题与修复依据

`artifacts/cover-20261111/diagnosis.json` 记录：样本 `BV179WW6oESh` 的原始封面为 1920×1080 JPEG，232388 字节，新下载与缓存文件摘要一致，Flutter 可成功解码为 720×405。缓存占用 66772730 字节，接近 67108864 字节上限；四路并发加载中，三次首次返回为空，但相应文件已经落盘、就绪状态存在，第二次读取均成功。并发容量清理重复删除旧文件，使维护异常影响已完成的加载结果；该诊断未修改生产源码或用户数据。问题复现不等同于修复验收通过。

### 实施与复现

- 本轮生产修复仅位于 `covers.dart`：通过 `_maintenance` 串行维护；捕获维护中的 `FileSystemException` 时仅记录 message/code，不影响已落盘文件的成功返回，没有平台特判或兼容层。
- 专项日志和 `regression.json` 位于 `artifacts/release-036/`。Mac 驱动日志含应用前置失败提示，但已连接测试应用并取得通过结果；这是原生组件交互证据，不扩称完整工作区人工视觉验收。
- 最终门禁首轮 analyze 因新增单元测试的两项 info 失败：冗余 `typed_data` 导入、可改为空值感知元素的条件列表。只对 `test/cover_cache_trim_test.dart` 做等价 lint 修复，生产代码与原生集成测试未变；失败证据保存在 `artifacts/release-036/gate-attempt-1/`，工程门禁重跑后全部通过，未放宽静态检查。
- Mac/Android 原生结果对应完整文件集指纹 `b33cf56cd9cced1db1fda608d1ac99b307b45bc0de1c293169d70f54c888abcf`；测试文件调整后指纹为 `ea897d83b65e5b2ed3d1b0630d0b148e7920c328aabbffe264a95335695ed47e`。沿用未改变的生产代码及原生场景结果，不宣称两端原生在最终完整文件集上重跑；差异记录见 `regression.json` 的 `nativeVerifiedSourceSha256` / `sourceAdjustment`。
- 滚动结果另存 `artifacts/release-036/scroll-performance.json`；此为 profile 模拟器的既定工程门禁通过，raster 开销仍高，不据此宣称物理设备达到 60 fps。
- Mac 原生入口为 `integration_test/cover_cache_test.dart`。先为该入口生成 Debug 配置，通过 `xcodebuild ... CODE_SIGNING_ALLOWED=NO` 构建并完成本地 ad-hoc 签名，再运行预构建应用。命令从项目根目录执行：

```sh
sh tool/flutterw.sh test --no-pub test/cover_cache_trim_test.dart test/download_attachments_test.dart test/discovery_artwork_test.dart test/artwork_playback_test.dart
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer sh tool/flutterw.sh drive --no-pub --driver=test_driver/integration_driver.dart --target=integration_test/cover_cache_test.dart --use-application-binary=build/macos/Build/Products/Debug/tingyu.app -d macos
```
