# 听屿界面规范

目标是简约、安静、有质感；减少常驻文字与重复入口，保持操作可发现、状态可确认、失败可恢复。D 哔哩粉为默认，A 暖白、B 深夜、C 樱粉共用 TingyuTokens，不分叉布局。

## 信息层级

- 保留必要文字：页面/导航名称、歌名、UP 主、歌词、时间、输入标签、选择项、空状态、确认和错误原因。
- 清楚的常用操作优先图标；提示和无障碍名称完整保留。图标不够明确时才配简短文字。不要用文字解释另一个已清楚表达的图标。
- 不常驻装饰性英文、重复副标题、切换操作说明、音频码率等技术文案。说明性资料收进“关于听屿”。
- 控件保持至少 48 px，键盘焦点可见；选中和状态不只依赖颜色，保持三主题对比度和减少动态效果。

## 入口与布局

- 页面标题只出现一次；音乐库左上圆形头像进入独立设置页，登录后显示 B 站头像，未登录或加载失败显示默认人像，收纳账号、收藏夹导入与偏好，搜索、下载、喜欢等页面不重复账号入口。
- 桌面侧栏底部只保留“设置”，移除“更多”及重复账号入口。桌面播放器不重复模式和队列入口。
- 播放页固定返回、进度及控制。返回用箭头，播放控制行依次为模式、上一首、播放/暂停、下一首、队列；下载与歌词使用图标。
- 点击模式图标直接轮换：列表循环 → 单曲循环 → 随机播放 → 列表循环，不弹选择窗口；长按/悬停提示当前模式。
- 歌单详情展示封面、数量和可选简介。工具栏为播放全部、下载全部、排序、多选；编辑名称与简介、添加歌曲、删除收进右上“更多”。上下文菜单保留短文字帮助辨认，删除仍要确认。

## 下载图标契约

| 状态 | 视觉 | 点击 |
|---|---|---|
| 尚未下载 | 下载箭头 | 创建任务 |
| 准备解析 | 箭头与活动圆环 | 正在处理，防重复触发 |
| 排队 | 时钟 | 查看下载管理 |
| 下载中 | 箭头与实际进度圆环 | 查看下载管理 |
| 完成 | 勾选与选中态 | 查看下载管理，不重复下载 |
| 暂停 | 暂停图标 | 继续下载 |
| 失败 | 叹号圆圈与错误色 | 重试 |

按钮不显示外置状态文字。百分比、状态和下一步写入 Tooltip/无障碍名称；详细失败原因在下载页。整张歌单下载显示聚合进度，完成后同样为勾选，失败项可重试。

搜索临时 CID 与解析后的真实 CID 需要映射到同一下载任务，避免已下载却仍显示普通箭头。暂停、失败和已下载都必须有对应点击行为，不允许静默无操作。

## 曲库整理

- 音乐库右上列表加号新建歌单；底部导航搜索入口唯一，左上头像进入设置，三个点只处理当前内容。
- 列表排序独立于播放历史，按音乐库/喜欢/具体歌单保存。默认顺序、最近添加、名称、UP 主四项有明确选中标记。播放全部使用当前展示顺序，不改变源歌单顺序。
- 多选由勾选列表图标进入；标题显示数量与全选，底部临时替换迷你播放器为加入歌单/下载/移除，退出后播放器恢复且播放不中断。移除仅出现在具体歌单，必须确认，保留库/喜欢/下载。
- 歌曲行直接播放，下载状态和更多常驻，小心形表示已喜欢；小屏无需重复播放和喜欢按钮。菜单在手机从底部展开，桌面使用居中菜单。
- 简介可选，旧数据无简介时默认为空；编辑/添加/解析 CID/批量移除后保留简介。

## 独立设置页（替代抽屉与悬浮菜单）

- 完整页面、固定返回，内容居中并限制宽度；手机隐藏主导航和迷你播放器，但播放继续。返回按钮和系统返回保留来源页输入、滚动和播放，直接进入设置时回音乐库。
- 顶部账号卡片展示登录状态，收藏夹导入收在卡片内；未登录时禁用导入并提示“登录后”。账号详情继续使用已验证的登录/收藏夹面板。
- 外观分组直接选择 A/B/C 主题，选中边框和勾选共同反馈；播放分组只保留音质；存储分组显示已完成下载占用并进入管理；关于置底。
- 设置内下载管理使用独立 `/settings/downloads` 子页面，返回设置且保留位置；不重复创建主导航。
- 全部卡片、文字、图标沿用 TingyuTokens 与 Pressable；暗色、暖白、冷白共用组件。

## 0.1.6 视觉层次

- 三主题使用不同的页面底色与明亮内容面；最近播放卡片和连续歌曲区使用内容面，避免每行一张带弧线的卡片。
- 迷你播放器采用独立圆角、间距、边框和轻阴影，与列表及导航区分。A 暖石墨灰配米白控制键，B 雾蓝配浅蓝控制键，C 浅粉配深粉控制键；颜色集中在 TingyuTokens。
- 导航选中只使用图标与文字强调，去掉大胶囊；已下载图标保留语义选中态，去掉填充底色。
- 搜索、喜欢、歌单沿用同一歌曲行，下载管理与设置沿用主题背景、文字及内容面；保留失败原因、确认与状态恢复入口。
- 播放器文字与控制键在三个主题分别验证正常文字对比度；共享组件继续覆盖四种尺寸。

## 0.1.7 查找与稳定状态

- 当前列表右上搜索图标展开本地筛选，搜索页仍用于 B 站联网检索，避免把两类结果混在一起。空结果保留清除入口。
- 队列当前歌曲使用强调色、统一三音柱及选中语义；播放时律动，暂停/停止时显示固定长短音柱；打开时定位，手动浏览后可通过准星图标重新定位。
- 切换主题即时生效，隐藏分类恢复时不补播旧颜色动画。同步导航不显示异步半透明等待态。

## 0.1.8 离线资料与导出

- 已下载行常驻播放与更多，补全歌词、导出歌曲、移除下载收在菜单；导出准备提供阻止重复误触的等待提示，系统保存窗口取消后回到原页。
- 下载完成与歌词状态分开；未匹配或失败可补全，不重下音频。导出完成明确封面/内嵌歌词是否存在。
- B 站 CC/AI 字幕用小字注明来源；不把视频画面文字或 AI 转录自动称作已校对歌词。
- 封面统一缓存并按展示尺寸解码，切换分类和主题复用文件。

## 向当前歌单添加歌曲与导航

添加歌曲是独立选歌任务：默认本地音乐库，本地搜索和多选，已添加不可重复选择，底部数量按钮统一提交；取消不提交。在线搜索作为子步骤，结果直接加到当前歌单，返回保留本地待选。任务内隐藏分类导航。分类切换恢复最后页面，再点当前分类回其根页；歌单返回音乐库首页。歌单/选歌的层级过渡使用现有 transition 时长的小幅位移和淡入，支持减少动态效果；分类间不混入旧层级退出动画。三个歌曲列表按需创建和绘制，进度通知只到进度条/歌词。

长列表向下超过一屏后，在内容区右下角显示 48 px 回顶箭头，位于迷你播放器上方；回顶后隐藏，支持减少动态效果。按钮更新不触发列表重建。

下载页默认“已下载”，右侧“下载任务”显示数量；开放文字 Tab 配字重和短线，和内容共用同一内容面。两页分别保留搜索和滚动位置，任务完成不自动跳页，空页保留 Tab。已下载按音频完成时间倒序，歌词/封面补全不改变位置。下载中的进度与暂停、失败重试保留在任务区。分组与排序只影响展示，不重排传输及播放队列。

搜索页前往哔哩哔哩是外部操作：独立按钮边界、外跳图标与简短 App/浏览器说明；Android 优先官方客户端，无法启动才打开浏览器，不使用内置网页。下载 Tab 使用最终确认的开放文字样式与内容共用暖白面，三主题都由设计变量驱动。

- 底部导航采用独立圆角内容面，图标在上、文字在下，选中态使用实心图标与字重；播放器与导航保留独立安全区域。
- 头像使用账号资料 face；无资料、无效地址、加载中或加载失败均回退为默认人像。点击进入完整设置页，返回保留原页面状态。


## 0.1.11 已确认稿落地

- 首次启动与未保存主题时使用 D 哔哩粉，保留显式保存的 A/B/C/D；强调文字采用可读的深粉，播放主按钮使用粉色并搭配深色图标。色值仅在 TingyuTokens 中定义。
- 手机音乐库左上为圆头像、右上为右对齐“随心听”。新建歌单只在“我的歌单”分区；本地搜索只在“歌曲”分区。桌面账号头像收在侧栏底部，避免与页面标题重复。
- 最近播放在前、封面歌单在后；真实曲库不添加演示歌曲。小屏/放大字体时卡片高度按字高增加，标题与操作区互不覆盖。
- 搜索页使用“听点新鲜的”、统一填充搜索框、轻量外部 B 站入口、四个实际关键词分类。下方只显示实际曲库/历史建议；关键词搜索、加载、空结果、错误及清除后均保留外部入口。
- 设置采用无外框账号区、四个可点击主题预览、连续偏好列表。账号、收藏夹、音质、下载管理、关于均复用真实业务；不引入模拟登录、模拟下载或虚构音质。设置不显示迷你播放器和底部主导航。
- 所有常规操作图标采用居中的固定盒，点击区域至少 48px；头像保持正圆，箭头、主题选中标记、导航与文字分别对齐。
- 队列播放中为动态音柱，暂停/停止为静态暂停符号；减少动态效果时使用静态音柱。保留无障碍状态名称，不常驻状态文字。点击当前队列曲目切换播放/暂停。


## 0.1.12 视觉修订

- 主题为哔哩粉、日出橙、月影蓝、夜间暗，默认哔哩粉。未发布阶段直接使用新主题标识，不做旧主题映射。所有页面、弹层、播放器和选中反馈使用同一组语义色。
- 首页用大幅继续收听、方形歌单和连续歌曲列表区分层级。歌单横向显示两张完整卡片及第三张的一部分，提示滑动。
- 设置的外观沿用首页横向卡片与露出规则；预览展示主题底色、封面、内容面及播放器。点击即时切换，选中边框、文字和勾选共同反馈。
- 返回、排序、置顶、下载、完成及队列图标统一为圆端线条。下载列表与页面背景连续，整行点击播放，副标题显示 UP 主。
- 队列使用动态音柱表达播放状态，暂停为低静态音柱；操作按钮仍遵循播放三角、暂停双线。拖动手柄排序，更多菜单保留上下移及移除。关于改为同风格底部面板。


## 0.1.13 已确认玻璃与状态规范

- 哔哩粉强调色精确使用 #FB7299，正文使用中性深色；品牌色与小号选中文字墨色分离。页面与歌曲列表连续，不再叠加白色大容器。
- 手机播放栏与底部导航覆盖滚动内容，采用共享 GlassSurface；5px 背景模糊、低不透明度表面与细高光保留背景封面和文字轮廓。末尾滚动空间按 Scaffold 实测底栏高度预留，系统安全区独立保留。
- 首页继续收听把标题/UP 主置于封面上方，连续内容与彩色封面形成层次。首页歌单与设置主题均保留两张完整卡片及第三张侧露，继续使用真实数据。
- 选择与下载完成共用圆圈对勾，未选为空圈，未下载为箭头；暂停下载用继续播放符号，失败才用重试。
- 已喜欢为实心红心，未喜欢为空心；下一首播放为跳转符号，加入播放队列为列表加号。队列操作标题显示歌曲及当前位置，使用“移至下一首 / 上移一位 / 下移一位 / 从队列移除”。
- 手机歌词使用底部表单面板，键盘避让；歌词偏移以 0.1 秒步进，取消不保存。
- Android 采用边到边背景和始终可见系统栏，状态栏/导航栏图标随主题明暗切换；覆盖此前隐藏系统栏的规则。


## 0.1.14 图标语义审查

- 加入播放队列使用列表加号；加入歌单使用文件夹加号；向歌单添加歌曲使用音符加号，避免仅靠 1px 位移区分不同操作。
- 下一首播放/移至下一首使用列表播放标记，立即切下一首继续使用跳转三角与竖线；查看播放队列使用列表音符，查看歌单使用带行目的收藏卡片。
- 回顶使用顶线与向上箭头，上移/下移使用带箭杆的方向箭头，展开保持向下折角。
- 状态圆圈对勾、播放/暂停、返回、外跳及相同功能在不同页面继续复用，不为了唯一性改变其语义。

- 封面统一使用独立的 4px 小圆角，覆盖继续收听、歌单、歌曲行、队列、播放页和迷你播放器；容器与玻璃胶囊圆角不随封面改变。横向卡片计数从 2.35 收敛为 2.15，适度放大封面并保留第三张侧露。
- 不使用 X：面板关闭用向下折角，退出选择用返回箭头，队列/歌单移除用圆圈减号，清空输入用擦除图标，删除下载用垃圾桶。行为、确认和无障碍名称保持。
