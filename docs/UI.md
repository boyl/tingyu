## 图标优先与冗余文案控制（2026-10-19）

共同原则：让明确的视觉符号承担操作表达，删除重复解释同一动作的常驻文字。优先从图标资源库读取；有合适资源不自行重画，没有或语义不足才登记修改/新增。

- 含义明确的常用动作优先图标按钮，不同时堆图标、动作文字和说明。倍速恢复用恢复图标；定时开始/取消用开始/关闭图标；歌词展示保留歌词图标与开关，不再加“歌词”文字或常规切换提示。
- 图标必须表达动作的关键语义并区别于当前状态。“播完暂停”需要同时表达曲尾与暂停，不能只用普通暂停双柱（易误认正在暂停）或方框1（缺少暂停含义）。新候选必须先登记、评审，再进入运行时。
- 去掉冗余常驻文案不等于隐藏语义：保留完整无障碍名称、按下/选中/禁用状态、48dp操作区、可见焦点，以及键盘或长按的按需名称。普通成功切换不重复弹文案；状态已可见时用状态本身反馈。
- 切换模式等符号难以完全消歧的操作，保留用户已要求的短时名称提示。错误、无效输入、破坏性确认、必要表单标签、倍率/时长/进度等有用信息继续显示；不能机械地把所有文字改成图标。
- 相同层级保持固定位置、尺寸、材质与强调方式，区分开始/取消等对立动作；不要靠大块按钮或重复副标题制造层次。
- 新页面、功能扩展和重构都审核：该文字是否提供符号之外的新信息？若只是重复已明确的动作，则移除常驻展示；若图标本身不能表达关键语义，先修图标，不用一段说明掩盖问题。

本条是后续开发规则；本轮第五版的新图标仍待设计确认，不等同于已发布行为。

## 稳定布局与控件表达（第十六版已确认，2026-10-19）

以下是可复用的现行开发规则，适用于后续新增与修改页面；遇具体布局冲突以用户最新确认稿为准，不借规范扩大改动范围。

1. **状态变化不挤动核心布局。** 开关控制内容显隐，不应重新计算相邻主体的大小、样式或位置。保留必要空间并使用克制的过渡；减少动态时直接切换。播放器唱片不得以“剩余高度”随歌词状态缩放，小屏/长标题通过限行及合理滚动适配，不能退化成小唱片。
2. **可见反馈对应真实控制量。** 连续调节使用实线轨道，除非用户明确需要分档，不添加虚线/密集刻度。字号显示明确数值，拖动同步改变预览与实际对象；端点、居中值及持久化分别验收。不得让滑杆看似变化、内容却不变。
3. **控件是同一套资源与主题。** 开关使用轻量轨道、白色滑块、主题开启色与中性关闭色，保留48dp触达、焦点及语义状态。不能把播放键的深色前景机械套到开关滑块，也不能每页另造开关。图标优先查询现有资源。
4. **恢复操作必须明确作用域。** 恢复字号放在“文字大小”标题行，只恢复字号；不使用悬空、无归属的重置图标。动作不够明确时保留短标签，不机械执行“全部图标化”。
5. **退出入口匹配容器。** 独立页左上返回，底部面板按既有把手/手势收起；已存在充分退出入口时不再叠加下箭头和“知道了”。移除冗余收起控件不等于删除应用品牌图标。设置保留来源返回。
6. **说明只保留用户需要的信息。** 自动模式用简短状态说明作用，工程术语、默认基准值和实现原理不作为常驻文案。保留常驻预览，不能为精简页面删掉已确认功能；辅助预览与常驻预览各司其职。
7. **搜索按用户理解匹配。** 收藏夹名称检索忽略大小写与前后空白，支持包含及多个关键词，不以大小写或精确全名制造假空态。筛选反馈结果数量，空态可恢复；既有选择不随搜索丢失。拼音/错字纠正另有明确需求才加入。
8. **效果图必须与真实几何和功能对照。** 原型确认后，原生验收须比较主体占比、字号、开关状态与操作前后坐标。进度变化或playing标志不能证明有声音，模拟、解码、系统输出和听感证据分开；视觉通过不得掩盖功能缺陷。

第十七版导入按钮已确认：底部单一通栏按钮与列表对齐；未选择显示中性禁用“选择收藏夹”，选择后主题主色“导入 N 个收藏夹”，导入中原位反馈并防重复。筛选不清除选择，不能将计数与动作拆成两端悬空控件。

第22版原生适配：保留唱片尺寸；安全区导致空间不足时，统一正文滚动区初始对齐歌词末端以保证当前歌词可见，用户可向上滚动查看完整封面。歌词开关不重排，长句不省略；当前行使用accentInk保证阅读对比，滚动使用320ms既有token。

- 交付检查：排查旧品牌与中英文粘连，检查无障碍名称；核对原生截图无额外音量说明，不能只检查组件代码。历史截图/既往版本记录保留为历史证据。

## macOS 原生工作区首版（2026-10-21，待人工确认）

本节仅适用于 Mac，不覆盖 Android 已确认的首页、唱片、底栏与导航约束。依据最新 Mac 设计修订：侧栏分组、真实封面内容架、资料库列表和悬浮核心播放栏；字号、几何和材质复用 TingyuTokens，按钮与图标复用 Pressable/TingyuIcon。

歌词在歌曲详情中与封面并排，不设常驻歌词侧栏或额外歌词页。待播在播放栏上方按需覆盖，开关不改变主内容宽度。倍速和定时归播放选项；模式和音量常驻；歌单新建靠近我的歌单。现有账号、歌词编辑及歌单选歌等子流程复用共享实现，后续可依据实机反馈继续调整桌面呈现。

实现和证据见 `docs/specs/macos-native-workspace.md`。调试构建与组件布局通过不代表真实账号、听感或分发验收。

### Mac 导航收敛（2026-10-22）

左侧是一级导航的唯一常驻入口：搜索、主页、资料库（最近播放、歌曲、喜欢、下载）、我的歌单及其创建按钮。主页不复制歌单网格或历史列表，只显示一个继续收听卡片，无记录时显示一个搜索引导空态。一级页面不显示返回按钮和重复的顶部小标题；歌曲详情保留返回来源。最近播放固定使用历史时间顺序，不提供全资料库排序或批量删除操作。新建歌单集中在左侧分组标题旁，空态不重复创建按钮。

### Mac 账号与导入承接（2026-10-22）

账号使用桌面专属弹窗：紧凑标题、明确关闭，二维码与扫码提示并排，加载/过期/失败状态在操作附近显示；不沿用手机外跳登录按钮、步骤时间线和功能说明卡。登录后显示可筛选、多选的收藏夹列表，底部固定紧凑导入按钮；成功显示结果，允许继续导入或在 Mac 工作区打开歌单。首页无播放历史但有歌曲时显示开始收听，不能因尚未播放而显示空资料库；保留既有左侧集中导航，不复制歌单网格。

### 当前 Mac 桌面规范（2026-10-24，优先于上述 Mac 历史记录）

取消主页。默认进入最近播放，无历史进入歌曲；旧 library 初始参数映射到歌曲，安卓入口不变。播放器三种窗口统一单排 80 高，保留切歌/播放、可拖动进度、模式、音量、队列与选项；窄窗省略常驻时间文字，模式名称用 Tooltip、无障碍名称和短时提示。播放栏/浮层用稳定实色材质；Mac 按钮以背景、边框与焦点反馈，48dp 范围不变、不按下缩放，不改变安卓反馈。品牌区缩小，搜索图标与内容基线统一。

详情使用有界封面列与歌词阅读列，封面/标题左对齐；无歌词为紧凑的匹配/导入模块，不新增歌词页、不固定队列占列。账号登录/收藏夹/结果三阶段分别分配空间，处理过程中不改变尺寸，所有入口一致。完整实现与验收见 docs/specs/macos-desktop-polish.md，确认图库见 design-review/2026-10-24/macos-desktop/index.html；10 月 21 日 HTML 只作为历史稿。

### Mac 账号与扁平设置补充（2026-10-24）

登录采用 420×380 紧凑窗口、单标题、居中二维码；正常等待无常驻刷新，过期和失败显示重试。登录成功同窗进入收藏夹。设置固定为外观、播放、存储三组，四种主题同时展示，音质和倍速直接修改，存储环图与明细并排。账号只在侧栏，定时只在播放器，Mac 设置移除玻璃选项。分组切换不改变窗口位置或尺寸，清理继续使用共享确认与数据保护流程。

### 跨端批量移除（2026-10-24）

Mac 与安卓共用多选工具栏：资料库删除、喜欢取消、歌单移出、已下载移除直接展示，不再藏入更多菜单。空选择禁用，点击后确认范围，处理中禁用重复点击。筛选仅提交当前可见选择；下载任务页不提供本批量删除。资料库删除清理关联引用且停止所选当前曲目，保留下载文件；其他操作仅影响所属集合。

### 批量传输弹窗（2026-10-24）

批量下载/加入歌单采用 420dp 宽上限、18dp 标题、24dp 内容留白；用横向定量进度与处理数量，避免微型进度圈裁切。处理中显示禁用的“处理中”，结束后显示“完成”，失败重试位于右侧同一操作区。状态预留高度，大字号长错误可换行和滚动，批量重试仅重新处理失败项。

### Mac 辅助交互修订（2026-10-24）

最近播放使用响应式大封面网格，沿用安卓首页标题、作者、封面的顺序；卡片仅提供播放。导航选中使用主题强调底色与加粗文字，图标同步着色；悬停和按下改变背景深浅，键盘焦点保留边框，禁止缩放移动。桌面操作弹窗宽度上限 420dp，标题 17dp，内容可滚动。音量浮层高 184dp，队列保留独立高度；播放栏按钮中心与滑轨对齐，时间单独成行。存储总量在内圆安全区域分行显示数字与单位并按需缩小。

## Windows 桌面复用（2026-10-26）

Windows 以当前 Mac 桌面规范为共同基线，复用同一工作区主体、主题、控件、布局与动画。MacWorkspace 与 WindowsWorkspace 保持独立入口，原生窗口、托盘、系统媒体和凭据由平台边界负责。Mac 使用 Command，Windows 对应使用 Ctrl 打开搜索和设置；不能把 Windows 键当作 Command 使用。后续平台独有功能在对应入口或明确的平台能力中扩展；共享改动必须检查两端。

应用图标从已确认的 Mac 黑底白色折带母版派生 Windows ICO。原生系统字体、窗口边框与系统对话框须通过截图另行核对；共用 Dart 代码本身不是像素完全一致的证据。

### 桌面设置底部可见性
设置面板的版本号和关于入口固定在底部，外观、播放、存储内容在中间独立滚动；800×600 窗口下仍完整可见且可点击。
