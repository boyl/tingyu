# 听屿界面规范

目标是简约、安静、有质感；减少常驻文字与重复入口，保持操作可发现、状态可确认、失败可恢复。A 暖白为默认，B 深色和 C 冷白只切换 TingyuTokens，不分叉布局。

## 信息层级

- 保留必要文字：页面/导航名称、歌名、UP 主、歌词、时间、输入标签、选择项、空状态、确认和错误原因。
- 清楚的常用操作优先图标；提示和无障碍名称完整保留。图标不够明确时才配简短文字。不要用文字解释另一个已清楚表达的图标。
- 不常驻装饰性英文、重复副标题、切换操作说明、音频码率等技术文案。说明性资料收进“关于听屿”。
- 控件保持至少 48 px，键盘焦点可见；选中和状态不只依赖颜色，保持三主题对比度和减少动态效果。

## 入口与布局

- 页面标题只出现一次；手机音乐库左上齿轮进入独立设置页，收纳账号、收藏夹导入与偏好，搜索、下载、喜欢等页面不重复账号入口。
- 桌面侧栏底部只保留“设置”，移除“更多”及重复账号入口。桌面播放器不重复模式和队列入口。
- 播放页固定返回、进度及控制。返回用箭头，播放控制行依次为模式、上一首、播放/暂停、下一首、队列；下载与歌词使用图标。
- 点击模式图标直接轮换：列表循环 → 单曲循环 → 随机播放 → 列表循环，不弹选择窗口；长按/悬停提示当前模式。
- 歌单详情展示封面、数量和可选简介。工具栏为播放全部、下载全部、排序、多选；编辑名称与简介、添加歌曲、删除收进右上“更多”。上下文菜单保留短文字帮助辨认，删除仍要确认。

## 下载图标契约

| 状态 | 视觉 | 点击 |
|---|---|---|
| 尚未下载 | 下载箭头 | 创建任务 |
| 准备解析 | 箭头与活动圆环 | 正在处理，防重复触发 |
| 排队 | 时钟 | 查看下载管理 |
| 下载中 | 箭头与实际进度圆环 | 查看下载管理 |
| 完成 | 勾选与选中态 | 查看下载管理，不重复下载 |
| 暂停 | 暂停图标 | 继续下载 |
| 失败 | 叹号圆圈与错误色 | 重试 |

按钮不显示外置状态文字。百分比、状态和下一步写入 Tooltip/无障碍名称；详细失败原因在下载页。整张歌单下载显示聚合进度，完成后同样为勾选，失败项可重试。

搜索临时 CID 与解析后的真实 CID 需要映射到同一下载任务，避免已下载却仍显示普通箭头。暂停、失败和已下载都必须有对应点击行为，不允许静默无操作。

## 曲库整理

- 音乐库右上列表加号新建歌单；底部导航搜索入口唯一，左上齿轮进入设置，三个点只处理当前内容。
- 列表排序独立于播放历史，按音乐库/喜欢/具体歌单保存。默认顺序、最近添加、名称、UP 主四项有明确选中标记。播放全部使用当前展示顺序，不改变源歌单顺序。
- 多选由勾选列表图标进入；标题显示数量与全选，底部临时替换迷你播放器为加入歌单/下载/移除，退出后播放器恢复且播放不中断。移除仅出现在具体歌单，必须确认，保留库/喜欢/下载。
- 歌曲行直接播放，下载状态和更多常驻，小心形表示已喜欢；小屏无需重复播放和喜欢按钮。菜单在手机从底部展开，桌面使用居中菜单。
- 简介可选，旧数据无简介时默认为空；编辑/添加/解析 CID/批量移除后保留简介。

## 独立设置页（替代抽屉与悬浮菜单）

- 完整页面、固定返回，内容居中并限制宽度；手机隐藏主导航和迷你播放器，但播放继续。返回按钮和系统返回保留来源页输入、滚动和播放，直接进入设置时回音乐库。
- 顶部账号卡片展示登录状态，收藏夹导入收在卡片内；未登录时禁用导入并提示“登录后”。账号详情继续使用已验证的登录/收藏夹面板。
- 外观分组直接选择 A/B/C 主题，选中边框和勾选共同反馈；播放分组只保留音质；存储分组显示已完成下载占用并进入管理；关于置底。
- 设置内下载管理使用独立 `/settings/downloads` 子页面，返回设置且保留位置；不重复创建主导航。
- 全部卡片、文字、图标沿用 TingyuTokens 与 Pressable；暗色、暖白、冷白共用组件。

## 0.1.6 视觉层次

- 三主题使用不同的页面底色与明亮内容面；最近播放卡片和连续歌曲区使用内容面，避免每行一张带弧线的卡片。
- 迷你播放器采用独立圆角、间距、边框和轻阴影，与列表及导航区分。A 暖石墨灰配米白控制键，B 雾蓝配浅蓝控制键，C 浅粉配深粉控制键；颜色集中在 TingyuTokens。
- 导航选中只使用图标与文字强调，去掉大胶囊；已下载图标保留语义选中态，去掉填充底色。
- 搜索、喜欢、歌单沿用同一歌曲行，下载管理与设置沿用主题背景、文字及内容面；保留失败原因、确认与状态恢复入口。
- 播放器文字与控制键在三个主题分别验证正常文字对比度；共享组件继续覆盖四种尺寸。

## 0.1.7 查找与稳定状态

- 当前列表右上搜索图标展开本地筛选，搜索页仍用于 B 站联网检索，避免把两类结果混在一起。空结果保留清除入口。
- 队列当前歌曲使用强调色、播放/暂停图标及选中语义；打开时定位，手动浏览后可通过准星图标重新定位。
- 切换主题即时生效，隐藏分类恢复时不补播旧颜色动画。同步导航不显示异步半透明等待态。
