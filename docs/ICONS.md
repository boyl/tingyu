# 图标资源管理规范

## 优先级与唯一入口

1. 先查 [资源预览](../resources/icons/index.html) 与 [登记表](../resources/icons/registry.json)。有适合的图标就复用同一ID、同一字形及相应状态语义。
2. 运行时优先 `TingyuIcon` 已映射图形；已有 Material fallback 同样属于资源库，通过登记的 `Icons.*` 使用。原型从 SVG 导出或登记字体读取，不在页面手写近似路径。
3. 现有资源没有或语义确实不适合时，才修改或新增。先说明复用不合适的原因，登记来源/许可、ID、语义、几何、主题颜色、状态和使用位置，再进行视觉确认。
4. 使用到、新增、修改和停止使用的图标均更新登记；不能只在页面、脚本、截图或临时文件中留一份孤立路径。设计候选标记为设计复用/待确认，不能宣称已实现。

## 保留既有语义

- 列表循环、单曲循环、随机播放：分别使用 Flutter Material `repeat`、`repeat_one`、`shuffle`，目前通过 `TingyuIcon` 未映射分支读取现有系统字体。不得改成手画双箭头、近似交叉箭头或重复形状。
- 模式按钮使用 `tokens.accent`，点击直接轮换并提示名称；图标、当前模式与无障碍名称保持一致。不因原型方便增加模式选择弹窗。
- 下载未完成使用原圆角托盘箭头 `download`，下载完成使用原圆圈勾选 `done`。完成态 `tokens.accent`，未下载 `tokens.text`，失败 `tokens.danger`；默认哔哩粉完成态是 `#fb7299`，不是文本强调色 `accentInk` 的 `#a93660`。
- 播放、暂停保留原实心三角和圆端填充双柱，不能改为空心三角或两根细线。播放键底色 `playerButton`、图形 `onPlayerButton`；默认哔哩粉分别 `#fb7299` / `#361522`。
- 当前项目自绘图标24网格、1.7线宽、圆端圆角；Material fallback 保持原字体形状，不能为了统一线宽私自描摹。
- 装饰性图标排除读屏；无文字动作提供名称与状态。保持48dp操作区，可见焦点，状态不能只靠颜色区分。

## 变更流程

- 检索登记表 → 复用已有ID → 无适合资源时提出修改/新增 → 更新运行时或设计候选及SVG对照 → 更新登记与可视化目录 → 对照原图检查 → 更新受影响截图与验收。
- 图标变更审查必须同时看形状、填充/描边、颜色token、状态、尺寸、光学位置、无障碍语义；不允许只看图形大致相似。
- 改动共享图标要列出全部使用位置并回归，不能让新功能顺带改变原下载/播放/导航资源。
- 第三方资源登记提供方与许可，字体许可放在资源旁。应用启动器图标仍由 `assets/branding/ribbon-outline.svg` 管理，与24网格业务图标分开。

## 维护命令与证据边界

```sh
python3 tool/icon_catalog.py
python3 tool/icon_catalog.py --check
```

执行目录为仓库根目录。导出器维护现有 painter 的 SVG 等价表示，运行时 painter 仍为几何来源；字体直接复制项目当前 Flutter SDK 资源，保留许可。登记表记录源代码和字体指纹，使用点变化也会使校验失败。新增或修改 painter 时须人工核对导出映射，不能仅更新指纹绕过审查。

仅资源/文档/原型改动进行源、资源、链接、原型检查；不据此声称 Android/Flutter 原生验收通过。运行时实现或图标变更还须遵循 ACCEPTANCE.md 的工程及人工视觉门禁。

## 图标表达与文字

遵循 [UI.md](UI.md) 的“图标优先与冗余文案控制”。含义明确的图标不叠常驻动作名和重复说明；读屏标签与状态必须完整。模式名称、错误、表单标签和必要确认按语义保留。

本轮新增 `endPause` 已按 layout-v12 进入运行时及资源登记：箭头指向填充暂停双柱，表达播完本首后暂停；现有三种模式字形不变。历史 candidates 文件仅用于设计追溯。恢复倍速、时钟和独立歌词入口复用现有资源。

## 语义与对齐修订（第六版，2026-10-19）

本节优先于前述第五版的具体控件安排：图标优先不等于一律去文字。歌词显示开关保留“歌词”文字标签，并独立保留完整歌词入口；全局隐藏歌词不能令独立入口消失。必要标签用于区分开关对象，不能作为冗余文案删除。

定时关闭以当前确认稿为准：选择“关闭”或时长，结束方式用分段选择；不再使用启用开关、播放图标或底部取消动作。选择有效时长即计时，修改时长重新计时，收起面板不取消。

图标与滑杆对齐以轨道中心为准，不以包含端点文字的整个容器居中；端点说明独立占下一行。加减使用资源库minus/plus，不使用字体加减字符代替。原型测量与设备实际布局验收分别记录。

0.1.19：关于使用 `assets/branding/ribbon-outline.png` 主题着色版，不使用音柱代替应用标识；目录类图标及选择状态通过现有 Material/Tingyu 映射登记。最新机器清单为41个SVG与31项Material字形；本轮未重画既有播放、下载、随机与循环字形。

第十六版确认补充：返回图标必须匹配独立页导航，底部面板优先既有把手/手势，不重复添加下箭头。恢复字号归入字号标题行并明确作用域；“图标优先”不等于隐藏动作对象。移除关于页冗余关闭图标时保留应用品牌母版。
