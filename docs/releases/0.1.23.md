本版让歌曲菜单操作有持续反馈，改善歌词与切歌稳定性，并更新定时关闭和 B 站登录交接。

## 功能

- 账号页提供“打开 B 站确认登录”主入口、无数字步骤时间线和二维码备用；返回后检查同一登录会话。
- 定时关闭前置“播完暂停”开关，自定义时长下拉展开滚轮，仅手动跨刻度时播放已确认音效。
- 喜欢、队列移位、加入歌单等操作保留来源面板并更新状态；取消喜欢和部分移除支持撤销，失败可原位重试。

## 优化与修复

- 修复部分歌词下半部被裁切的问题，按实际文字与逐字换行测量显示区域。
- 修复异步歌词返回或切歌时唱片尺寸闪变，保留小屏与大字适配。
- 歌曲菜单“下载／已下载”互斥，图标与其他行对齐；批量下载失败不再计为成功。
- 更新官方新登录地址校验，保留旧官方地址兼容，隔离刷新前的旧会话结果。
- README 按预览、下载、功能与常见问题整理，开发细节移入独立指南；旧预览页的品牌展示文字统一为 tingyu。
