本版为 Mac 与 Android 加入自动播放缓存、复用缓存下载，并修复 Mac 交互及本地记录恢复问题。

## 功能

- 自动缓存默认开启，最多 2 GB，按最近使用淘汰；关闭后停止新增，已有缓存仍可复用。
- 缓存与下载分开保存和统计；点击下载时复用完整缓存或当前传输，成功后保存到下载位置。
- Mac 内联清理确认，Android 独立存储页与底部清理面板；播放缓存默认不勾选，下载与播放记录保留。

## 优化与修复

- 修复初始化较慢时周期保存可能覆盖本地播放记录的问题，退出账号保留本地资料；无法恢复此前已丢失的数据。
- 优化 Mac 搜索状态、错误重试、定时输入、完整队列、歌单选择、歌词匹配入口与窄窗口布局。
- 复选框选中前后统一方形，修复方框变圆圈的不一致。
