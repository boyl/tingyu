# 0.1.31 封面重复加载修复发布

## 范围与兼容性
- 用户要求继续发布，并明确确认 Mac 同步；版本 0.1.31+32，Android versionCode 2032。发布一个 arm64-v8a APK 和一个 Mac DMG，Windows 保留旧版链接。
- 共享 CoverCache 对 B 站 i 数字 CDN 的 `/bfs/` 等价图片地址统一缓存身份；路径、图片变体、查询参数及其他域名仍独立。旧缓存与原失败退避保持，不清数据、不改播放或推荐布局。
- Android 保留开发签名，Mac 为未公证 ad-hoc 签名；完整 Spec 见 [search-discovery](specs/search-discovery.md)。

## 验收标准
- 同一封面在搜索和播放解析之间换 CDN 地址时，内存、并发请求与磁盘缓存共用，不重复下载。
- 手机及实际 Mac 工作区，精选与列表两个入口点击播放后 CID 正确解析并播放，逐帧保留同一解码图像；其他封面和推荐批次不变。
- 旧缓存可读，不同图片/变体/非 B 站来源不错误合并。
- 最终版本执行完整工程及隔离 Android 原生/真实播放门禁，顺序构建两端安装包，验证版本、架构、签名、摘要和最终 APK 系统栏。
- 发布后回读公开状态、标签提交、两项资产及下载链接，服务端 digest 与本地一致。
