# 本轮开发清单与执行计划

状态：本轮实现与工程回归完成，0.1.18测试包已交付模拟器；人工验收及公开发布未完成。以下清单保留任务定义，实际完成与待验以文末及版本验收记录为准。

## 已确认设计与不做项

- 歌曲详情以layout-v12/player.png为最新确认稿：歌曲资料旁下载状态；歌词正文纯展示；倍速与定时在进度条上方；第一排为模式/上一首/播放暂停/下一首/队列；第二排为居中歌词标签＋全局开关和独立歌词入口。
- 倍速采用已认可的刻度、恢复图标、对齐加减及滑杆。定时采用第七版关闭/时长与结束方式分段，不用播放图标、不重复两个开关。
- 透明度采用第四版的整体调节置顶、导航/播放分控简化布局；设置保持普通页面，不做整页磨玻璃。
- 存储为应用空间环形占比＋分类明细；账号单入口与唯一收藏夹导入；启动屏tingyu＋真实包版本。
- Mac原型、桌面图标及桌面打包暂停；不做桌面歌词/悬浮歌词；不构建其他Android ABI；不重绘既有图标、不用示例数据写入真实曲库。

## 执行顺序与完成门槛

1. 基线与规格：W01/W02，梳理旧代码/测试/数据；冻结最新确认布局和状态矩阵。产出可追溯基线与差异清单。
2. 播放核心：W04/W05/W06/W09，先验证自然结束、模式/随机/队列、倍速、后台计时及恢复契约，再做上层绑定。
3. 详情与歌词：W03/W07/W08/W10/W16，将已确认交互落地，补完真实歌词数据链路、异步隔离及图标映射。产出真实运行截图和专项检查。
4. 设置与平台：W11/W12/W13/W14/W15，落地透明度、存储、账号、启动/图标及外跳；每个子流程覆盖初始/空/处理中/失败/恢复。
5. 整体验收：W17；相关模块用Red/Green/Refactor证明行为，analyze/test、隔离Android集成、真实服务专项、四主题视觉、字号与系统栏。真实账号、物理听感、蓝牙/来电/厂商后台须单列真机待验，不由夹具替代。
6. 文档与测试包：W18；清理旧规范矛盾，生成同源验收记录、包清单及SHA。按RELEASE固定命令仅构建arm64-v8a；自动测试仅tingyu-regression/5558，不动用户手工设备数据。用户设备仅同签名Release adb install -r。
7. 人工确认与发布：先用户测试实际应用；修复问题并重跑受影响检查。公开Release/推送标签等按当前授权执行，不把历史发布授权当作本轮立即发布许可。

## 当前事实与风险

- 本轮确认的是原型设计；原型通过不代表真实音频/后台/账号/设备通过。
- FEATURES仍以0.1.17记录，部分源码已有超出文档的歌词/队列工作，第一阶段须核对，不能重复实现或误报完成。
- 自动透明度阈值、厂商启动器对透明图标的处理和歌词源质量需要真实环境证据。
- 交付不降级、不卸载、不清用户数据；不通过修改预期或覆盖确认截图来让测试变绿。
