# 0.1.33 推荐优化发布验收

## 范围与验收标准

- Android arm64-v8a 与 Mac 更新为 0.1.33+34；Windows 沿用 0.1.31，不声称含本次推荐优化。
- 推荐供给、兴趣轮换、反馈排序和手机标签单行横滑按 [搜索推荐 Spec](specs/search-discovery.md) 验证；保留本地歌单、喜欢、下载与播放接口。
- 最终版本需通过工程及隔离 Android 导航/交互/导出/滚动/真实播放门禁，同一 APK 完成系统栏、签名、唯一 ABI 与 SHA 校验。
- Mac universal Release、ad-hoc 签名、DMG 完整性和挂载内应用版本/签名校验；发布前后回读标签提交、两项资产、版本、大小和摘要。

- 更新版本号前，337 项离线测试通过、4 项跳过；Android 与 Mac 共享推荐页原生交互、真实匿名推荐搜索通过。停滞与结束事件归因按 RED/GREEN 修复，详细记录在 Spec。
