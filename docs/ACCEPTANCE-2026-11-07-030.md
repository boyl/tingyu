# 0.1.30 搜索推荐页发布

## 范围与兼容性
- 用户于 2026-11-07 授权发布；Android 0.1.30+31，提供 arm64-v8a APK 与 Mac DMG，versionCode 2031。
- 搜索空闲页提供最多六首横滑精选与首批十首连续列表，探索标签、换批、接近底部自动追加；保留搜索和 B 站外部入口。规则与行为验收见 [search-discovery](specs/search-discovery.md)。
