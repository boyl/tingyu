# 0.1.14 图标语义、封面与面板关闭

用户反馈：加入队列与加入歌单撞形；封面偏小且圆角过大；队列移除和其他关闭操作不使用 X。

## 审查与修改

| 场景 | 修改后 |
|---|---|
| 下一首播放 / 移至下一首 | 列表与播放标记，区别于立即跳转下一首 |
| 加入播放队列 | 列表加号 |
| 加入歌单 / 批量加入歌单 | 文件夹加号 |
| 向当前歌单添加歌曲 | 音符加号 |
| 查看歌单（含桌面侧栏、导入结果） | 带列表行的收藏卡片，区别于播放队列列表音符 |
| 回到顶部 / 上移 / 下移 / 展开 | 顶线箭头 / 带箭杆的上箭头 / 带箭杆的下箭头 / 下折角 |
| 队列与歌单移除 | 圆圈减号 |
| 面板关闭、退出选择 | 下折角、返回箭头 |
| 清空输入 / 删除下载 | 擦除图标 / 垃圾桶 |

已检查全部 UI IconData 调用点和自绘映射。保留同一语义的复用：选择/下载完成的圆圈对勾（用户明确要求）、播放/暂停、返回、外跳、拖动、相同功能在不同页面的入口。旧 close/cancel IconData 映射也不再绘制 X；业务调用点已改用对应语义图标。

封面使用独立 artworkRadius=4，覆盖通用 Artwork、继续收听裁切、歌单空封面、搜索分类图。玻璃胶囊、表单和头像保持各自的容器圆角/圆形。横向卡片比例由 2.35 调整为 2.15，手机首页横向封面延伸至右屏幕边缘，标题与其他内容保持原边距。设置主题仍是两张完整卡片与第三张露出。
