# 播放与设置体验修订

状态：第十六/十七版已纳入 0.1.20 开发版发布。工程门禁和 arm64 包已完成；模拟器听感与真机仍待验。

## 目标与兼容

保留哔哩粉等四主题语义、既有图标资源与浅色材质，修正实际实现和确认稿之间的布局偏差。原播放、歌词、队列、下载与账号数据不迁移；Mac暂停。

## 方案

- 唱片主体在390宽示意下246直径；360宽按比例约226，不再从剩余高度反算尺寸。长标题两行，必要时内容滚动；唱片、标题、进度与主控不因歌词开关而跳位。
- 歌词区保留稳定高度，只做内容显隐和轻微淡入淡出，减少动态时即时显隐；独立入口不受开关影响。
- 通用开关采用36×22轻量轨道、白色16圆形滑块、关闭灰轨道；触达区至少48×48。图形/位置与读屏状态共同表达，不使用黑色滑块或随意修改主题。
- 自动透明度：保留常驻双栏预览，自动/手动收成同一浅底分段控件；自动状态只显示“根据页面内容调节”，不展示实现术语“默认基准”。手动及原位预览契约沿用glass-v15。
- 收藏夹搜索：trim、全角ASCII/空格规范化和大小写折叠后做名称模糊包含；空格分词时全部关键词匹配、不要求相邻，不引入无依据的错字/拼音猜测。示例bgm可匹配BGM，结果数随筛选变化，空态可清空；批量选择不因筛选丢失。
- 独立账号/导入页左上使用back，底部面板才使用drag handle；关于已有把手，移除额外下箭头，应用品牌图标保留。
- 倍速无虚线/点状刻度，连续实线细轨道；仍保留原预设、0.05精调、加减和图标恢复1×。
- 字号16–32示意连续调节、显示具体px数值及即时预览；正式实现以逻辑像素和文字缩放验收。恢复默认收进文字大小标题行，明确仅重置字号，不清其它设置。

## 缺陷与待诊断

播放无声音：先区分播放器解码/轨道与音量增益、Android媒体音量/音频焦点、模拟器到主机输出。保留当前用户曲库，不先重装清数据；进度前进/playing=true不能证明有声音。实施前建立可复现场景与检测证据。用户补充：开始有声，操作其他界面一段时间后无声，进度仍继续；当前采样时已暂停，不能用于判定失声瞬间的音频状态。

## 已确认：系统返回规则

用户2026-10-19确认：这里指系统返回键/手势。首页不在顶部时先回到顶部，再次返回退出；已在顶部直接退出。其他底部分类先回首页，后续按首页逻辑处理；不自动重置首页已有滚动位置。设置页保持原来源返回，不强制首页；设置子页、键盘和弹层仍按原有层级先处理。实现时分别验证首页顶部/非顶部、其他分类带首页历史滚动位置、从各分类进入设置及返回。

## 导入按钮修订（已确认）

底部保留单一通栏按钮，左右与列表内容对齐。未选择时灰色“选择收藏夹”，选择后为主题主色“导入 N 个收藏夹”，不再把计数和动作分到两端。导入中原位显示进度状态并防重复；失败后保留剩余选择供重试。第十七版原型仅演示未选/已选/处理中，不真实调用导入。其余第十六版方案已确认。

实施决策：复用现有依赖，名称检索覆盖Unicode小写、全角ASCII与空格，不新增整套Unicode归一库或拼音/错字猜测；旧歌词三档通过兼容字段保留，新字号使用独立持久化值。
