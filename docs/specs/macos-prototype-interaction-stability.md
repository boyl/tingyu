# Mac 原型交互稳定性

状态：Implemented；工程回归通过，真实浏览器验收待运行。2026-10-21。用户授权“全面排查处理”，直接修复当前 macos-v3，保持现有入口，不改 Flutter 或发布。

## 目标与兼容

保留苹果播客方向、右栏歌词/待播、歌单就近新建、内联筛选、就近播放浮层和分组设置。修复导致交互后质感下降的 DOM 重建、状态漂移、焦点失效和布局突变。

## 根因证据

- renderDock 在播放、喜欢、速度变化时整块 innerHTML 替换，滑杆回到硬编码进度，触发按钮被销毁。
- setTheme 调用 modal('settings')，重置设置滚动、折叠组、透明度和音质。
- 选择变化 renderMain，筛选与排序缺少真实统一集合；hidden 可能被 display:flex 覆盖。
- popover 遮罩拦截下一次工具点击；modal 和 popover 分开管理，可叠加；子步骤覆盖 lastFocus。
- 定时结束方式直接改已提交变量；后台收起不能回滚全部草稿。
- 多首曲目共享 liked，菜单对象与正在播放对象混淆；新建/改名/排序只提示未反映到界面。

## 方案与范围

在 design-review/2026-10-21/macos-v3 内拆分可测试状态模型与视图/控制器；原 HTML 入口保留。播放条和滑杆保留节点，选择与筛选局部更新；集合位置按页记录；浮层单一生命周期、确定返回路径和焦点；统一状态视觉与减少动态。

## 验收

1. 播放/喜欢/速度不销毁 dock 节点，进度、音量和喜爱按曲目保留。
2. 切主题不销毁设置窗；音质、透明度、折叠与滚动保留；主题和明暗状态一致。
3. 每集合独立保存查找、排序、选择和滚动；筛选不删除数据，排序实际生效，全选仅针对可见项。
4. 歌词/队列切换只更新伴随栏，主列表不重建；当前行样式、控制值同步。
5. 任一时刻只有一个临时容器；连续切换工具一次生效，弹窗子步骤有返回，关闭焦点可恢复；Esc/Tab 不穿透。
6. 定时草稿未改不重置截止；后台丢弃草稿，收起按修改提交；结束方式同属草稿。
7. 新建/改名/加入/下载等演示操作实际更新演示数据，不以无效 toast 冒充完成。
8. 800×600、1024×768、1280×800 无核心控制裁切；全量视觉与浏览器键盘行为如未实测须明确 NOT RUN。
