# 三点操作完成后的返回位置

按已确认的方案实施。一次性操作成功后回到来源页并反馈，失败留在原面板重试。喜欢与推荐沿用各自的业务状态，取消喜欢及屏蔽推荐支持撤销。连续调整队列、选择多个歌单时保留面板，歌单选择的返回和完成各自回到正确层级。编辑取消返回菜单，保存返回详情。音量和批量下载接替菜单。排序完成后显示排序后的列表。复用手机与桌面的公共菜单，保留现有数据格式。

验证覆盖来源页、取消、重试和连续操作，Android 原生导航使用独立回归模拟器。
