## 目标与基线

基于 boyl/tingyu main 当前 0.1.28+29，实现可直接运行的 Windows x64 桌面版本。UI 交互与视觉以现有 macOS 桌面工作区、现行 UI 规范及已确认截图为基线；不得重做为另一套 Windows 风格界面。

已确认：项目已有 Windows runner、libmpv 音频依赖、SMTC、托盘与打包脚本。lib/main.dart 的 createRouter 仅在 Platform.isMacOS 时使用 MacWorkspace；Windows 尚未接入这套桌面入口。主题未明确配置共同字体，需核查字体度量和许可证。当前 shell PATH 未发现 Flutter / Dart / CMake，不能据此认定整机未安装。

## 方案与兼容

沿用现有 Flutter MVC 职责划分：共享模型、Riverpod 控制器、桌面视图；Windows 音频、系统媒体、凭据、托盘、窗口由现有边界服务实现。避免复制 Mac UI 形成第二套代码。Android 路由及交互保持回归覆盖，macOS 既有行为不得退化。

一致性范围包含导航、页面、弹层、播放栏、歌词、主题、图标、间距、字号、动画、悬停/按下/焦点、键盘及滚动反馈。原生标题栏、文件选择器、系统媒体面板及系统字体的跨系统差异须逐项调查；未经确认不得将其自动排除于用户要求。若 Apple 字体不能合法分发，记录阻塞及候选共同字体，不能直接宣称完全相同。组件截图不能代替原生窗口与真实音频证据。
