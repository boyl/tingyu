# 跨端批量移除
状态：实现与本轮验证完成；用户已授权 Mac 与安卓一起增加。

## 范围与兼容
共享控制器和选择工具栏，沿用现有 Flutter 架构、Pressable 与确认框，不新增依赖。歌曲资料库删除清理歌曲、歌单引用、喜欢、历史、待播，保留下载文件；删除当前歌曲停止播放。取消喜欢仅修改喜欢；歌单移除仅修改该歌单；下载移除仅删除已下载音频及离线资料，保留歌曲和喜欢。下载任务取消不纳入本轮。

- [x] 回归覆盖持久化、关联范围、当前曲目、写入失败、确认取消及窄屏；工程验收与 Mac 构建。安卓独立模拟器集成验证按环境记录，不操作用户数据。
