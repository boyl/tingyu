# 登录续期与网络故障隔离
状态：代码与清理完成，最终发布快照工程门禁通过；真实账号跨天与物理设备验收未执行

## 目标与兼容
- 扫码保存 Cookie 和 refresh_token；旧纯 Cookie 记录继续可读，需重新扫码才能获得续期令牌。
- 沿用控制器/服务/系统安全存储边界；不把任何凭据写入普通数据库或日志。
- 启动及运行中每 30 分钟触发检查；成功检查后 24 小时内不重复，失败下次检查重试。
- 网络、风控错误保留账号资料；仅 nav 明确 -101 或 isLogin=false 才清除展示。

## 实现与安全
- 使用 B 站 passport HTTPS 检查、刷新与确认端点；本机 RSA-OAEP SHA256 生成 correspond 路径，不用第三方加密服务；禁止自动重定向。
- 新凭据和旧确认令牌同一安全存储记录落盘后再确认；确认失败可重启重试。
- 单飞续期、串行存储、会话代次隔离退出/重新扫码的迟到响应。
- 系统安全存储增加最近成功账号资料，离线重启仍可展示；资料不代表服务端认证成功。
- 协议依据：https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/login/cookie_refresh.md （研究者的一手逆向协议记录，非稳定公开 API）。服务端强制下线不可保证自动恢复。确认请求的幂等行为尚待真实服务验证，未知失败保留待确认记录并提示重试，不擅自视作成功。旧版不识别新安全存储格式，降级时需重新扫码。
