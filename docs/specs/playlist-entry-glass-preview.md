# 歌单入口与玻璃预览遮挡修复

状态：工程验证通过，待人工视觉确认

## 目标
- 手机用户无需横向寻找即可访问全部歌单。
- 调整透明度时能完整观察实际播放栏和导航栏。

## 范围与兼容
- 首页保留原横向歌单架及新建按钮，不改封面比例、首页层次和歌曲数据。
- 沿用现有主题、Pressable、图标登记与自动/手动透明度存储。
- 不提交、推送或发布安装包，除非用户另行授权。

## 原因与方案
1. 首页“我的歌单”仅有新建按钮和横向列表。让标题及右侧箭头组成可点击入口，打开独立“我的歌单”纵向列表；保留原新建按钮。列表展示封面、名称与歌曲数，点击进入既有详情，返回恢复来源；空列表提供新建入口。
2. 当前预览用 Opacity 隐藏其他控件，活动滑杆保留原布局，因此可能遮挡底栏。透明度页上方保留调节区域，下方为无遮挡的实际页面预览区域；先完成布局，再开始手势，禁止在拖动中移动滑杆。保留三项调节、自动/手动、预览开关与恢复默认，窄屏允许调节区域内部滚动。

- 手机可从“我的歌单”进入全部列表；长名称、多歌单及空状态无溢出。
- 列表进入详情，按钮/系统返回正确，首页滚动及播放状态保留。
- 三项滑杆覆盖透明度端点；拖动时滑杆矩形不变，播放栏和导航栏均不与可见控件相交。
- 松开、手势取消、进入后台时退出临时预览；自动模式保持原行为。
- 320 宽、常规手机及 1.6 字体缩放检查；静态分析、相关组件回归及 5558 原生导航回归。
