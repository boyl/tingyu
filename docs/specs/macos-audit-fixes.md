- 播放优先已下载、匹配音质的完整缓存、网络；歌曲/分 P/音质策略作为缓存键，不存凭据或签名 URL。

- 新缓存服务负责容量、文件完整性、网络生命周期；播放器负责音频源；下载管理器负责永久保留；控制器只编排，分别适配 Mac 与安卓 UI。
