# 0.1.4 简约界面与下载反馈验收

本轮范围：按用户确认的“必要文字保留、操作优先图标”统一界面，取消播放模式弹窗，收拢账号入口，修复下载状态反馈。设计规则见 [UI.md](UI.md)。

## 变更

- 模式直接轮换，控制行只保留模式、上一首、播放/暂停、下一首、队列；删除整行模式说明、重复队列入口和桌面重复控件。
- 手机账号/收藏夹与设置进入“音乐库 → 左上三横菜单”；桌面账号收进侧栏“更多”。其他页面不放常驻登录按钮。
- 下载图标反映准备、排队、实际进度、完成、暂停与失败；完成点击进入下载管理，暂停/失败可继续/重试。整歌单下载也显示聚合进度。
- 统一搜索临时 CID 与真实曲目下载任务的映射，修复已下载却没有状态反馈的问题。
- 去掉英文页眉、重复页面副标题、播放页常驻码率和“返回/下载/歌词”操作文字。保留标题、歌曲资料、歌词、导航和必要反馈；长按提示与无障碍名称完整保留。
- 歌单常驻工具改为图标，改名/删除收进更多；设置名称精简，资料说明收进关于；歌词服务错误与歌词正文分离，避免把长错误文案当作歌词展示。

## 人工复核

1. 展开播放器，连续点击左侧模式图标，确认直接轮换且没有弹窗；长按查看当前模式。
2. 点击下载，观察进度圆环；完成为勾选，再次点击进入下载管理。验证已经下载的旧歌曲也显示完成图标。
3. 手机切换搜索、下载、喜欢，确认不再重复显示登录入口；从音乐库三横菜单进入账号与收藏夹。
4. 新建歌单，检查图标工具栏；在更多里改名/删除，验证取消与确认。
5. 检查暖白/深色/冷白：页面只保留必要文字，图标可辨认、歌曲与歌词清楚，返回和播放不中断。

### 模拟器失声未关闭

用户确认：发生在本机模拟器，进度继续，暂停再播放也无声。诊断时 Android 音轨活跃、媒体混音未静音/压低、无欠载，Mac 音量正常，默认输出为内置双声道扬声器。未定位到应用下载逻辑引发静音的证据，不能声称修复。

项目 AVD 启动器禁用不需要的麦克风输入，保留音频输出（Android 官方列为 Bluetooth 路由干扰的规避措施；当前内置扬声器环境不据此推断同一根因）：https://developer.android.com/studio/run/emulator-troubleshooting 。人工 AVD 保留资料冷启动后仍须复听。物理手机并未报告该失声问题。
